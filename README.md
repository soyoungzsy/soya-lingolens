# Soya LingoLens

[![Chrome Manifest V3](https://img.shields.io/badge/Chrome-Manifest%20V3-4285F4)](https://developer.chrome.com/docs/extensions/develop/migrate/what-is-mv3)
[![Version](https://img.shields.io/badge/version-0.3.0-176B52)](manifest.json)
[![License: MIT](https://img.shields.io/badge/license-MIT-D89324)](LICENSE)

**在英文网页上保留原文阅读，选中或停留即可理解，并把真正遇到的英文沉淀成自己的复习记录。**

Soya LingoLens 是一个面向中文母语学习者的 Chrome 英语伴读扩展，特别适合浏览 X/Twitter、英文资讯、博客和产品网站。它不会把整页英文替换成中文，而是在需要时显示轻量翻译卡，并在 Chrome 侧边栏保存学习记录。

当前版本可直接以“未打包扩展程序”方式安装，不需要构建、服务器或开发环境。

## 适合谁

- 英语基础一般，希望一边浏览真实网站、一边积累词句的中文用户。
- 经常浏览 X/Twitter、英文新闻、博客、产品文档或海外社区的人。
- 不喜欢浏览器整页翻译，希望保留英文原文进行中英对照的人。
- 希望自动保存遇到过的词句，之后搜索、收藏和复习的人。

## 不适合什么场景

- 不能替代专业词典、人工翻译或严谨的法律、医疗、学术翻译。
- 免费翻译依赖第三方公共服务，质量、速度和可用性没有 SLA 保证。
- 不应在公司机密、私人邮件、财务、医疗或含个人敏感信息的页面使用。
- 暂不支持 Safari、Firefox、移动端 Chrome、跨设备同步或学习记录导出。
- Chrome 内部页面、Chrome 应用商店页面和内置 PDF 查看器不允许普通扩展注入。

## 一眼看懂主要功能

| 场景 | 操作 | 结果 |
|---|---|---|
| 不认识一个单词 | 鼠标选中 | 显示中文释义、音标、词性、常用义、例句和朗读 |
| 看不懂一句话或一段话 | 选中整句或段落 | 结合附近文本生成自然中文，保留英文原文 |
| 按钮文字点了就会跳转 | 鼠标停留 3 秒 | 不触发点击，显示紧凑翻译卡 |
| 再次遇到同一内容 | 选中或停留 | 优先读取 30 天本地缓存，减少等待 |
| 想回顾学过什么 | 打开扩展侧边栏 | 搜索、筛选、收藏、删除、标记掌握并返回来源页 |
| 想听发音 | 点击播放按钮 | 优先调用系统中的美式女声 |

其他能力：

- 针对 X/Twitter 动态页面提取当前选区附近的推文语境。
- 相同英文忽略大小写和多余空格去重，并累计遇见次数。
- 自动记录原文、翻译、网页标题、来源链接和时间。
- 支持右键菜单和 `Alt+Shift+E` 快捷键。
- 页面浮层使用 Shadow DOM，尽量避免与网站样式冲突。
- 免费模式无需密钥；可选 OpenAI 模式改善复杂语境翻译。
- 不包含分析埋点、广告或开发者自建的数据收集服务。

## 3 分钟安装

### 1. 获取代码

在 GitHub 仓库页面点击 **Code → Download ZIP**，下载后解压。也可以使用 Git：

```bash
git clone https://github.com/soyoungzsy/soya-lingolens.git
```

### 2. 加载到 Chrome

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开页面右上角的 **开发者模式**。
3. 点击 **加载已解压的扩展程序**。
4. 选择解压后的项目根目录。正确的目录中应直接看到 `manifest.json`，不要选择它的上一级目录。
5. 确认扩展列表中出现 **Soya LingoLens**，并且开关处于开启状态。
6. 建议固定到浏览器工具栏。
7. 刷新已经打开的英文网页。安装前已打开的页面必须刷新一次，内容脚本才会生效。

安装成功后，点击工具栏中的 Soya LingoLens 图标，应看到右侧复习栏。

## 第一次使用

### 选词或选句

1. 打开普通英文网页或 X/Twitter。
2. 用鼠标选中一个英文单词、句子或段落。
3. 松开鼠标，翻译卡会出现在选区附近。
4. 翻译成功后，记录会自动进入侧边栏。

### 翻译可点击的按钮

把鼠标放在 1–4 个英文单词组成的按钮或链接上，停留满 3 秒。扩展会在约 0.5 秒后静默预取，到第 3 秒显示紧凑翻译卡，不会替你点击或跳转。

常见按钮词使用内置词库；联网翻译会缓存 30 天，最多保留 1000 条缓存。

### 复习记录

点击扩展图标打开侧边栏，可以：

- 搜索英文、中文或来源网页。
- 只看收藏内容或待复习内容。
- 播放美式英语朗读。
- 标记“已掌握”或恢复为“继续复习”。
- 删除记录，或点击来源标题返回原网页。

相同英文再次出现时不会创建重复卡片，而是增加“遇见次数”并更新最近来源。

## 翻译模式、费用与隐私

### 免费基础翻译（默认）

- 优先使用 Google Translate 公共端点；失败时回退到 MyMemory。
- 单词的音标、英文释义和例句来自 Free Dictionary API。
- 常见短按钮优先使用扩展内置词库，不发送网络请求。
- 无需 API Key，不向本项目作者付费。
- 公共服务可能限流或不可用；复杂长句的连贯性有限。

### OpenAI 语境翻译（可选）

1. 打开侧边栏，点击右上角设置。
2. 选择 **OpenAI 语境翻译**。
3. 填入自己的 OpenAI API Key 和模型名称并保存。

OpenAI API 独立按实际用量收费，价格和账单由 OpenAI 管理。API Key 仅保存在本机 `chrome.storage.local`，不会写入源代码或发送给本项目作者。

开启“发送附近段落”后，扩展会把选中文字附近最多约 1500 个字符一并发送给所选服务。关闭后只发送选中的英文。完整说明见 [PRIVACY.md](PRIVACY.md)。

## Chrome 权限说明

| 权限 | 用途 |
|---|---|
| `storage` | 在本机保存设置、学习记录和翻译缓存 |
| `sidePanel` | 展示复习侧边栏 |
| `contextMenus` | 在选中文本的右键菜单中提供翻译入口 |
| `http://*/*`、`https://*/*` | 在英文网页中读取用户主动选中的文字并显示浮层 |
| 翻译及词典域名 | 直接请求翻译、词典或可选 OpenAI 服务 |

扩展不会主动上传完整浏览历史。只有触发翻译时，选中文字和用户允许的附近语境才会发送给翻译服务。

## 数据如何保存

- 学习记录和设置保存在当前 Chrome 配置的扩展本地存储中。
- 最多保留最近 3000 条学习记录和 1000 条翻译缓存。
- 缓存有效期为 30 天。
- 卸载扩展或清除扩展数据会删除本地记录。
- 当前版本没有云端账号、跨设备同步、导入或导出功能。

## 更新版本

如果通过 Git 安装：

```bash
git pull
```

如果通过 ZIP 安装，请下载新版并覆盖原目录。更新文件后：

1. 打开 `chrome://extensions/`。
2. 在 Soya LingoLens 卡片上点击 **重新加载**。
3. 刷新正在使用扩展的网页。

不要删除或移动 Chrome 当前加载的项目文件夹，否则扩展下次重新加载时会失效。

## 常见问题

### 选中英文没有反应

- 安装或重新加载扩展后，刷新当前网页。
- 确认扩展已启用，并被允许访问当前网站。
- Chrome 内部页面、应用商店和内置 PDF 页面无法注入。

### 一直显示“网络请求失败”

- 检查网络能否访问 Google Translate 或 MyMemory。
- 在设置中切换翻译模式。
- 使用 OpenAI 时检查 API Key、余额、模型名称和网络访问。

### 悬停按钮没有翻译

- 需要持续停留 3 秒。
- 为避免误触，只处理 1–4 个英文单词、40 个字符以内的按钮或链接标签。
- 同一按钮在 30 秒内不会反复弹出。

### 发音不是预期的女声

扩展优先选择 Samantha、Ava、Allison、Susan、Microsoft Aria 或 Google US English。实际可用声音由操作系统和 Chrome 决定；若这些声音未安装，会回退到系统可用的 `en-US` 声音。

## 项目结构

```text
manifest.json      Manifest V3 权限、入口和快捷键
background.js      翻译服务、本地词库、缓存、去重与存储
content.js         网页选区、悬停检测、X 语境提取和翻译浮层
sidepanel.html     复习侧边栏结构
sidepanel.js       搜索、收藏、删除、掌握状态和朗读
options.html       翻译模式及隐私设置页面
options.js         设置读写逻辑
lib.js             默认设置和共享数据函数
ui.css             侧边栏及设置页视觉样式
PRIVACY.md         数据处理和第三方服务边界
LICENSE            MIT 开源许可证
CONTRIBUTING.md    参与开发和提交规范
```

这些文件构成完整的可运行扩展；项目不依赖 npm、构建步骤或外部服务器。

## 本地开发与验证

修改源码后，在 `chrome://extensions/` 中点击扩展卡片的 **重新加载**，再刷新测试网页。

提交代码前运行：

```bash
node --check background.js
node --check content.js
node --check sidepanel.js
node --check options.js
python3 -m json.tool manifest.json > /dev/null
```

至少手动验证：

- 普通英文网页的单词、句子和段落选区。
- X/Twitter 动态页面的选区及附近语境。
- 英文按钮停留 3 秒的紧凑翻译。
- 侧边栏的搜索、收藏、删除、标记掌握和来源链接。
- 免费翻译与可选 OpenAI 模式。
- 扩展重新加载后，学习记录仍然存在。
